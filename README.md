# Contact Book

A simple beginner-friendly Python project for managing contacts using a command-line interface.

## Features

- Add a new contact
- View all contacts
- Search for a contact
- Delete a contact
- Simple menu-driven interface

## Technologies Used

- Python
- Dictionaries
- Functions
- Loops
- Conditional statements
- User input

## How to Run

1. Make sure Python is installed.
2. Open a terminal in this project folder.
3. Run:

```bash
python contact_book.py
```

## How It Works

Contacts are stored in a Python dictionary while the program is running. Each contact contains:

- Name
- Phone number
- Email address

## Example Menu

```text
===== Contact Book =====
1. Add Contact
2. View Contacts
3. Search Contact
4. Delete Contact
5. Exit
```

## Learning Objectives

This project helps beginners practice:

- Creating and calling functions
- Working with dictionaries
- Using `if-elif-else`
- Using `while` loops
- Taking input from users
- Managing simple application data

## Limitations

Contacts are stored only while the program is running. Closing the program clears the contacts.
